📋 ¿Cómo configurar las tablas en Supabase?

1. Crea un proyecto gratuito en supabase.com.

2. Ve al SQL Editor en Supabase y pega el script que se encuentra en el archivo supabase_schema.sql de tu proyecto.

3. Copia la URL del proyecto y la anon public key de Project Settings > API y pégalas aquí.
